<LessonMeta time="3 min" audience="Designers and staff preparing venue content" level="Core" accent="services" />

[Open ANC Studio](https://classroom.basheer.app)

Choose **Design** above the familiar brief box. The same creation sequence now ends with actual designs on the canvas. Each page holds a generated file that you can inspect, refine and download.

## Describe the result

Write what you want to make, the exact copy and how many designs you need. Choose **Artwork**, **Venue concept** or **LED boards**, and select a format when available.

Use the paperclip to add source material. Supply the actual venue photo for a venue concept, and the intended logo or artwork for a board. For LED boards, include each display's name and exact pixel dimensions.

## Give the assistant useful source material

Attach any source images you already have with the paperclip. For a named brand, venue or existing artwork, the assistant also looks for relevant visual references in the background and checks the image before using it. If it cannot confidently identify an essential reference, it asks you for the missing logo, artwork or venue photo.

Select **Create the designs**. The familiar progress sequence reads the brief, plans the requested outputs and generates the files. Select the outline during planning if you need to review it before creation continues.

## Review and refine on the canvas

Use the page arrows to browse the generated designs. **Design file** downloads the selected file. **Refine** lets you describe a change to the selected design; the new version is added as another canvas page, with the earlier version retained. You can also request motion from a selected image.

For LED board packages, review the proof, exact display dimensions and any missing details. The final-render control appears with the proof's credit total when it is ready for approval. Approve only after checking the content and dimensions, then download the resulting files.

Check copy, logos and visual details before production. Venue outputs are proposed treatments, not photographs of completed installations.
