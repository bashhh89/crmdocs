[Open ANC Studio Design](https://classroom.basheer.app/design)

Design creates files you can preview, refine and download. Your brief, source images and completed versions stay together in the saved design.

## Start with the output

Open **Design** in ANC Studio and choose:

- **Campaign artwork** for a poster, sponsor graphic or social asset.
- **Venue concept** to show a new display treatment in your supplied venue image.
- **LED board package** for proofs and final files sized for specific displays.

Write the brief with the exact copy, intended visual direction and requested format. For boards, include each display's name and pixel dimensions. Supply the logo or artwork that belongs on the board. For venue concepts, supply the venue image you want to use.

## Add source material

Use **Upload images** for JPG, PNG or WebP files. You can add up to five references, with each image under 20 MB.

For an existing file in the content library, choose **Choose from FTP**. Use your normal staff access if sign-in is requested. Open the relevant folder and select **Use reference** beside the image. The selection returns to your design and is copied in when you generate. The original remains in the library.

## Generate and refine

Select **Generate design**. The workspace shows progress and saves completed files. You can return through **Your designs** to reopen the result.

To change artwork, select an image version, enter the change and choose **Create revision**. The previous version stays available. Check the result's copy, logos and visual details before using it.

To create motion, select an image, describe what should move and choose **Make motion clip**. Play the result in the workspace and download the MP4 when it meets the brief.

## Review board proofs and export finals

Board packages first produce labelled proofs. Review the artwork, copy and display dimensions. Correct any flagged missing details with a revision.

When the proof is ready, review the displayed credit total and select **Approve & render finals**. The final files are checked against the display dimensions. Use **Download** on the selected final file.

Venue outputs are concept visualizations. Review them as proposed treatments before presenting them or using them to guide production.
