## Prepare the experience

Use **Prepare** and the bottom toolbar to choose the venue, screens, and content. Clicking a board opens its Content panel. Use **Play on** to target one screen or all active screens.

- **ANC library** includes an ANC venue showcase, the ANC Studios football reel, a motion takeover, and a static signature.
- **Video** accepts MP4 or WebM files and loops automatically.
- **Logo / image** accepts PNG, JPG, or WebP. Transparent logos display against a black screen face.

Files can be up to 100 MB. **Fit** preserves the whole image or video. **Fill** crops it to cover the display. Use audience views and event/day lighting to check the result.

The supplied venue models are illustrative planning environments. Advanced retains the existing detailed configuration tools and venue-model import.

## Save the project and media

Open **Projects**, enter a project name and optional client/campaign, and choose **Save project & media**. The saved project includes the venue, displays, sponsors, uploaded media, attendance, lighting, and selected audience view. Imported binary GLB venue models are also stored when saved.

Wait for **Saved · Version …** before leaving. If you keep editing while a save is running, those newer changes remain unsaved. **Save a copy** creates a separate project.

**All projects** is your workspace library. Open a project to continue editing. **Archive** is reversible and makes its presentation unavailable while archived; **Restore** reopens access. Unsaved work requires an explicit discard before another project replaces it.

## Present and share

**Present** clears the editing controls for a presentation from your current browser. For sales handoff or a client link, choose **Share**, then **Publish & copy presentation link**.

The recipient sees the project identity, audience views, content player, camera tour, and before/after comparison. Editing controls are available only in the workspace.

Draft changes stay separate from the published presentation. Choose **Publish latest & copy link** when the new version is ready. If a teammate has changed the draft, reopen it and review their version before saving or publishing.

**Revoke presentation link** prevents future access to that presentation address. Publishing afterward creates a new link. Anyone with a presentation link can view it; revoking it does not retract files someone already downloaded.

## Control the presentation

The **Screen content** player controls pause/play, restart, the timeline, and video sound. Matching screens share video playback. Camera tour controls are separate.

**Before / after** temporarily turns displays off without changing the configuration. **Show design** restores them.

## Keep workspace access

In **Projects → Workspace**, choose **Copy workspace access link**. Keep it somewhere private so you can reopen the same projects on another device or recover access after clearing browser storage.

This access link grants editing access to every project in the workspace. Give it only to teammates who need that access. Give clients the presentation link from **Share**.

Projects and media live on the server. The browser remembers which workspace to open. Existing browser-only configurations remain in Advanced: open one, return to the showroom, and save it as a project to migrate it. Add any missing local uploads again before saving.
