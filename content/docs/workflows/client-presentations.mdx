## Chapter 1 — Home

The Home tab gives the designer one calm view of the presentation workspace. Use it to understand the workload, choose the right way into an assignment, return to active work, and read client response before deciding what deserves attention next.

### Read first, then choose

The totals across the top show the current state of the workspace: presentations, live client links, and opens. Treat those numbers as context for your judgment, not an automatic instruction about what to make.

When the assignment is clear, choose the starting path that fits it:

- **Venue Magic** when the venue itself should lead the story.
- **DealDeck** when the team needs a structured sales narrative.
- **Partner page** when the immediate job is an approved branded surface.

The **Recent presentations** list keeps active work close. Search when the list grows, read each status, and open the presentation that needs a human decision. Analytics sits beside the work so the team can review actual response before choosing what to refine, publish, or share next.

<Callout type="info">
  Treat Home as the morning briefing: the totals focus attention, while the designer selects the entry point, reviews the work, and signs off on what advances.
</Callout>

## Build the story in one canvas

Open **Presentations**, start from the ANC slide library, and arrange the finished pages in the order the client should experience them. The top bar keeps the authoring and delivery controls together, while the slide library remains available on the left.

- Use **Client / Venue** once to update the deck title and cover.
- Drag slides to reorder the narrative.
- Use **Media** to place approved images and video into supported slide areas.
- Select **Save** before switching workflows or leaving the builder.

## Use spatial assets selectively

Select **Spatial** when a flagship venue visual will materially strengthen the pitch. The library contains reusable arena, stadium, and ribbon-display assets with controlled viewing and approved artwork surfaces.

Choose the asset, select the display surface, add partner artwork, review the result, then select **Apply to slide**. The same scene has a deterministic fallback for environments where the interactive view is unavailable and for printed output.

<Callout type="info">
  Spatial is a premium emphasis tool, not a requirement for every page. Use it where rotation, scale, or branded placement helps the client understand the opportunity.
</Callout>

## Direct the room's pace

Select **Motion** to open Motion Director. Preview any of the seven curated motion styles on the real presentation before applying it.

- **Apply to this slide** keeps the effect local.
- **Apply to full deck** gives the presentation one consistent pace.
- **Replay** lets you judge the transition again before committing.

Select **Cinematic** to preview the same deck as a scroll-driven room experience. It uses the same slides and published content, so there is no second version to maintain.

## Personalize without breaking ANC

Open **Partner** to use Partner Lens. Enter the prospect website or choose an approved logo from the media library. Prospect branding is restricted to Partner pages and approved scoreboard, ribbon, or signage zones; ANC navigation and typography remain ANC.

This keeps personalization useful and controlled instead of recoloring the entire presentation.

## Ask the agent to operate the workspace

Open **Agent** and describe the outcome in plain language. The assistant uses the same registered capability map as the builder, so newly registered tools enter its product knowledge automatically. It can build, edit, reorder, duplicate, strengthen copy, apply motion, select a slide, or open the correct feature.

After each request, read the execution receipts to see exactly what changed and what was skipped. Safe draft actions run immediately. Save, Share, PDF export, navigation, and starting over appear as explicit confirmation cards, so persistent or client-facing actions stay under your control.

## Publish only after proof

Select **Share** to name a client link, decide whether viewers must identify themselves, and take the deck live — the full flow is in [Tracked Client Links](/docs/workflows/tracked-client-link). Then open **Preflight check** from the **⋯** menu and select **Run preflight**.

**Ready to send** means all seven checks passed against the published version:

- the saved builder matches the published version;
- the frozen client copy is intact;
- a valid client link points to the deck;
- the content is client-ready — a client name is set and no template placeholders remain;
- every referenced image, video, and PDF loads correctly;
- every slide opens cleanly on desktop and phone;
- the published PDF has one page per slide.

If any check is blocked, fix the reported item, publish again, and rerun Preflight. Do not send a stale or blocked result.

## Give the client a Decision Room

The shared presentation is not a passive attachment. The Decision Bar lets the client **Request revision**, **Ask question**, or **Approve / advance** without leaving the deck. Those actions return to the presentation owner alongside the normal viewing analytics.

The operating sequence is simple: build, personalize, direct the motion, preview, publish, prove, then send.
