# ANC Hub

ANC Hub is the app launcher for the ANC platform. Use it when you need to jump between Proposal Engine, CRM, Services Dashboard, Operations Workspace, Forms, and Operator Docs without remembering separate URLs.

Open it at [proposals.anc.com/hub](https://proposals.anc.com/hub).

## When to use it

- You are not sure which ANC tool you need.
- You need to move between proposals, CRM, service operations, forms, or docs.
- You want a quick shortcut to a new estimate, RFP Analyzer, Pipeline, or Product Catalog.
- You are helping a user find the right starting point.

## What you can open

| Tile | Use it for |
|---|---|
| CRM | Accounts, contacts, opportunities, reports, and Scout. |
| Proposal Engine | Estimates, RFP analysis, proposals, and scoping workbooks. |
| Services Dashboard | Events, venues, tickets, staffing, and field operations. |
| Operations Workspace | Operations tables for displays, walkthroughs, maintenance, and related records. |
| ANC Forms | Shared request intake for companies, people, and design flows. |
| Operator Docs | Platform guides, training notes, workflow docs, and support material. |

## How to use it

1. Open [ANC Hub](https://proposals.anc.com/hub).
2. Choose the app tile for the work you need.
3. Use the Proposal shortcuts panel for fast actions such as **New estimate**, **RFP analyzer**, **Pipeline**, or **Product catalog**.

## Access notes

ANC Hub uses your ANC Microsoft identity. Each app still controls its own permissions, so seeing the launcher does not automatically mean every destination app is available to every user.
