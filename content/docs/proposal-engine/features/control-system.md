# Control System

Control System builds a recommended control-system BOM from screen requirements. It is designed for LiveSync-style jobs where server count, render capacity, matrix routing, racks, licensing, and related hardware need to be estimated consistently.

Open it at [proposals.anc.com/admin/livesync-calculator](https://proposals.anc.com/admin/livesync-calculator).

## Access

Control System is available to Admins, Product Experts, and platform owners.

## When to use it

- You need a control-system BOM for one or more screens.
- A job has live video, outdoor displays, large pixel counts, or multiple render outputs.
- You need a reviewed hardware, soft cost, and license total.
- You need an exportable workbook for the generated BOM.

## Inputs

For each screen, enter:

- Screen name.
- Pixel width and height.
- Physical width in feet.
- Whether live video is required.
- Whether the screen is outdoor.

## Outputs

- Server equipment.
- User stations.
- Interconnect, routing, KVM, racks, and trigger hardware where needed.
- License and integration lines.
- Processor advisory.
- Review flags and assumptions.
- Hardware, soft cost, license, and grand totals.
- Excel export for review.

## Review checklist

- Pixel dimensions are correct.
- Live video is marked correctly.
- Outdoor screens are marked correctly.
- Review flags are resolved before using the BOM commercially.
- Processor advisory is checked against the final LED/control design.
