# Email Intake

Email Intake helps convert messy inbound estimate requests into structured estimator drafts. Use it when a request starts as an email, screenshot, pasted notes, or client message instead of a clean workbook.

Open it at [proposals.anc.com/tools/email-to-quote](https://proposals.anc.com/tools/email-to-quote).

## When to use it

- A client sends rough requirements by email.
- The request includes multiple projects or display areas.
- You need AI help extracting screens, venue notes, scope, and assumptions.
- You want to create an estimator draft from the extracted request.

## What it does

- Reviews the pasted or uploaded email content.
- Extracts project names, display rows, dimensions, pitch, and notes where available.
- Groups displays by project.
- Creates estimator-ready draft data for review.
- Sends the user into the Estimator when a draft is created.

## Typical workflow

1. Open [Email Intake](https://proposals.anc.com/tools/email-to-quote).
2. Paste the email text or provide the request content.
3. Run the review.
4. Check the extracted projects and display rows.
5. Create the estimator draft.
6. Open the new estimate and finish pricing.

## Review checklist

- Client and venue are correct.
- Each requested display appears once.
- Dimensions and pitch were extracted correctly.
- Missing values are marked for review instead of guessed.
- Assumptions are carried into the estimator notes.
