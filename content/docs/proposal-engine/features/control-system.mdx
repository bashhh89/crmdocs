## What changed

Previously, selecting CMS inserted a fixed allowance automatically. The estimator now calculates the actual equipment and services instead. The CMS tab, estimate summaries and Excel export use that itemized package. Existing saved estimates recalculate when opened; their old allowance is not the pricing basis.

The control-system selection rules and catalog prices have not changed as part of this correction.

## Estimate and review CMS

1. Enter the LED displays and select their products, dimensions and quantities.
2. In the financial questions, select **Yes** for **CMS (Content Management)**.
3. Open **CMS requirements** and confirm the scope. Sports venue is on by default; professional stadium, software license and per-display live video are off by default. Change them to match the job.
4. Open the **CMS** worksheet to review the calculated equipment, quantities, unit costs, selling prices and selection reasons. Dimensions and requirement changes recalculate the package automatically.
5. Review the **Budget Summary** and **Margin Analysis**, then select **Export .xlsx** for the itemized workbook.

TVs are excluded from LED pixel sizing. Invalid dimensions or missing CMS catalog items stop the calculation instead of substituting a fixed allowance. Review the assumptions and scope before sending a quote.

The [standalone Control System](https://proposals.anc.com/admin/livesync-calculator) remains available for separate system studies and saved-job loading. It uses the same calculation and is not an extra step required for estimator CMS pricing.

## Processing is separate

The automatic CMS amount covers the control system, not a complete processing package. Existing processor allowances elsewhere in the estimate are not confirmation of full processing pricing. Processor classes, ports and fiber-converter counts must not be treated as a verified processing quote. Processing pricing remains a separate open item.

## Access

Control System is available to estimators, product experts, administrators, and other authorized estimating roles.
