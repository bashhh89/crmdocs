## What changed

Current saved estimator jobs now load their LED displays into Control System at the calculated pixel dimensions, including cabinet sizing and quantities. TVs are excluded from LED pixel sizing with an explicit note. The estimator identifies its CMS amount as a budget allowance and links directly to Control System.

The control-system selection rules and catalog prices have not changed as part of this correction.

## Load and review the job

1. In the estimator, follow **Control System** beside **CMS pricing basis: budget allowance**, or open it from the sidebar.
2. Under **Load from an estimated job**, search for the client, project, or venue. Choose the correct saved estimate when names repeat.
3. Check the loaded pixel width, pixel height, physical width, and any exclusion notes. Name the system so its result and export are recognizable.
4. Review **Live video** and **Outdoor** for each screen. Check **Sports venue**, **Professional stadium**, and **Include software license** against the actual scope.
5. Select **Build estimate**. Review the screen plans, equipment quantities, unit costs, selling prices, margins, assumptions, and warnings.
6. Select **Export Excel** to download the itemized Control System workbook for review.

Loading a job does not settle its live-video requirements. Building a Control System package does not automatically replace the saved estimator allowance.

## Processing is separate

When **Processing (per screen)** says that processing carries no price, the displayed total covers the control system only. Processor classes, ports, and fiber-converter counts are design guidance, not a priced processing package. Do not treat that total as a complete processing quote.

## Access

Control System is available to estimators, product experts, administrators, and other authorized estimating roles.
