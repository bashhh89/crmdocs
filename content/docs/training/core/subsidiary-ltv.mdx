## Read the four fields

| Field | What to read |
| --- | --- |
| **Subsidiary LTV (Revenue)** | The revenue currency total. |
| **Subsidiary LTV (Margin)** | The margin currency total. |
| **Subsidiary LTV (Won Deals)** | The number of won deals. |
| **Subsidiary LTV (Last Rollup)** | The date and time of the last refresh. |

The layout is shared across Company records. You do not need to save a separate layout for each company. Check **Last Rollup** before using the figures in an account review.
