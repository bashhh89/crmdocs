# What's New: June 2026

You do not need to learn a new CRM. The useful changes are mostly small quality-of-life improvements: smoother tables, better search, stronger assistant behavior, cleaner workflows, and more stable email/calendar activity.

<Callout title="Same workflow">
Keep using the same pages, views, and dashboards. This page is just a heads-up on what should feel better.
</Callout>

## What You Should Notice

### Client Pages Look Like ANC Pages Now

Client-facing Pages now use ANC branding consistently. The page header shows ANC on the left and the client/account identity on the right. If a client logo is stored on the Page, it can render there; if not, the Page shows clean initials based on the account name.

What this means for users:

- Client-safe public Pages have a polished ANC look.
- Restricted Pages still require the right access link.
- Draft Pages do not accidentally publish.
- Copy Link still works.
- Sections still expand and collapse.
- Mobile viewing has been checked.

### The ANC Guide Is Back On The Side

The in-CRM guide launcher now sits as a side rail beside the app instead of a bottom floating widget. Click **Guide** to open the full visual guide.

<Shot src="/img/screenshots/crm/openanc-guide-side-rail.png" caption="The in-CRM guide now sits on the side rail, so users can open help without covering the working area." />

### Search and Lists Should Feel Cleaner

Saved views, filters, record tables, and search received improvements. For ANC, this matters because most day-to-day work happens in filtered views like proposal pipeline, active opportunities, account lists, and dashboard drilldowns.

Users should still open the same pages, but lists should feel less fragile when filtering, sorting, or moving columns.

<Shot src="/img/screenshots/crm/t-all-deals.png" caption="Cleaner lists matter because most CRM work starts from filtered record views like all deals, active opportunities, and owner-specific queues." />

### Scout Should Be More Reliable

The update includes assistant reliability improvements. This should help Scout with reporting and operational tasks.

Good things to ask after rollout:

- "Show me my open opportunities."
- "Which proposals are due this week?"
- "Give me the top open deals by value."
- "Enrich this contact, but only update sourced fields."

<Shot src="/img/screenshots/crm/openanc-guide-side-rail.png" caption="Assistant and guide surfaces support the same goal: get users to the right record, action, or answer faster." />

### Workflows Get Stronger

Workflow improvements give the operations team more room to build clean automations later without changing how users work.

Examples this can support:

- routing new deals
- renewal reminders
- closed-won digests
- load-balanced assignments
- intake follow-up

### Email and Calendar Activity Should Be Better

For users, the goal is simple: account and opportunity pages should show more useful activity context with fewer sync surprises.

## What The Team Checks

Before changes are announced as ready, the team checks:

1. Login
2. Search
3. Company, Person, and Opportunity pages
4. Saved views
5. Dashboards
6. File previews
7. Mobile loading
8. Scout answers
9. App widgets and command actions
10. Email and calendar activity
