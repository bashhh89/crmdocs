## What a placement record holds

Each placement is its **own record** — one sponsor, in one position, at one game. That granularity is the whole point: it lets you see everything a sponsor has running *and* everything happening at a given property, without rebuilding either view in a spreadsheet.

The record carries the full context of the game:

- **Game date and time**, plus the **home team** and **away team** (both linked to their Company records).
- **Sponsor** — linked to the sponsor's Company, so the account always reflects what's running.
- **Position** — which board slot: homeplate full, homeplate half, small homeplate, or other.
- **League and season** — MLB, NBA, NHL, MLS, NFL, NCAA — so season-level filtering and reporting stay clean.
- **TV coverage detail** — home, away, and national network fields, which is what makes national-versus-local reporting possible later.
- **Execution status** — scheduled, executed, not executed, national game, or postponed.
- **Notes** — anything unusual about the game or the run.

Records are named so you can read them at a glance in any list — date, matchup, sponsor, and position all in the title.

## Logging a new placement

1. From **All Media Placements**, create a new **placement record**.
2. Set the **game date, home team, and away team**.
3. Set the **sponsor** and the **position**.
4. Set **league and season**, and add TV network detail if you have it.
5. Leave status as **scheduled** — it changes only after the game.

The placement links to the sponsor's account automatically once the sponsor is set, so the Company record picks it up with no extra step.

## Marking what actually ran

Each placement has a **status** — scheduled, executed, not executed, national game, postponed. Set it as things run. That status is the difference between "what we planned" and "what actually aired" — and it is what verification and contract tracking read downstream.

- **Executed** — it ran as planned.
- **Not executed** — it was scheduled and did not run. This is a flag, not a failure to hide: it is exactly what surfaces make-good conversations early.
- **National game** — coverage changed the picture; the record keeps that distinction so national and local never get lumped together in reporting.
- **Postponed** — the game moved. Keep the record; update the date when the makeup game is set.

## It all ties together

Every placement links to the **sponsor's account** (so the account reflects what's running) and can link back to the **opportunity** it came from (so sold-versus-delivered stays connected end to end). Those links are what power the next two lessons: [Nielsen Verification](/docs/training/media-sponsorship/nielsen-verification) confirms what the placement records claim, and [Sponsor Contracts](/docs/training/media-sponsorship/sponsor-contracts) compares them to what was committed. The rollups all land in [Your Dashboards](/docs/training/media-sponsorship/dashboards).
