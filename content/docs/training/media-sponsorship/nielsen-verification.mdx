**After this lesson** you'll be able to run the monthly verification round and always know what's confirmed versus what's still outstanding.


## How verification is tracked

Verification lives as its **own records** — by sponsor, by league, by month — so the whole trail sits in one organized place instead of a side spreadsheet.

## The monthly routine

Each month there's a verification record per active sponsor and league to confirm:

1. Open the list of this month's verifications.
2. Work down it, sponsor by sponsor.
3. Mark each **correct** or **incorrect** (with a note if something was off).
4. The outstanding ones stay visible until they're done.

**Or just ask:** *"What verifications are still pending this month?"*

<Callout title="It can remind you">
The system can prompt the monthly round so it doesn't get forgotten — so the verification work comes to you instead of relying on someone to remember it.
</Callout>

## Mark correct or incorrect

Open the verification record and set whether it's **correct**, adding a note if something didn't check out. That keeps a clean, auditable trail of what passed and what didn't.

## See verified vs. pending

The verification records show the status per sponsor and month. Filter to what's **outstanding** so nothing gets missed.

**Or just ask:** *"Which sponsors still need verifying for this month?"*

## Now you try →

Open this month's verifications, mark one as correct, and filter the list to see what's still pending.
