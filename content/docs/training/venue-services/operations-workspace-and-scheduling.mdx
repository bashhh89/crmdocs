## Start in the Operations Workspace

Open **Operations** from the Services dashboard. The full ANC Operations Workspace appears inside the dashboard, with the table-first areas used for displays, venues, walkthroughs, documents, inventory tracking, and other operating records.

<WhereThisLives tool="services" path="Services dashboard → Operations" />

<Callout type="info">
Use the Operations Workspace for structured operating records. Use the focused Events, Venue Profiles, Inventory Reports, and Shift Scheduling pages when you need a guided workflow with validation and review controls.
</Callout>

## Classify an NFL event

1. Open **Events** and choose **Create event**.
2. Enter the event details and select the venue.
3. Open **League** and choose **NFL**.
4. Review the date, times, and staffing before creating the event.

<WhereThisLives tool="services" path="Services dashboard → Events → Create event → League" />

## Add a venue logo or cover image

1. Open the venue and switch to **Settings**.
2. Choose the logo or cover-image upload area.
3. Add a PNG or JPEG file and check the preview.
4. Keep the image only after confirming it belongs to the correct venue.

The uploaded image remains attached to the Venue Profile, so it is available the next time the page opens.

<WhereThisLives tool="services" path="Services dashboard → Venues → open a venue → Settings" />

An incomplete checklist cannot be submitted. When the physical count differs from the expected quantity, the report calls out the variance. Low counts and damaged items can also create a visible restock flag.

<WhereThisLives tool="services" path="Services dashboard → Inventory Reports" />

## Preview and import a shift schedule

1. Open **Shift Scheduling** and choose **Import Schedule**.
2. Upload a CSV or Excel file.
3. Preview the rows before importing.
4. Resolve unmatched venues, staff, invalid times, and duplicates.
5. Import only the approved rows, then confirm they appear under **Upcoming shift schedule**.

The import template supports these core columns: **Venue, Shift Name, Date, Start Time, End Time, Required Staff,** and **Staff**.

<Callout type="warn">
The preview is the review boundary. Do not skip it: confirm the venue, date, time, staffing requirement, and duplicate status before adding rows to the schedule.
</Callout>

<WhereThisLives tool="services" path="Services dashboard → Shift Scheduling → Import Schedule" />
