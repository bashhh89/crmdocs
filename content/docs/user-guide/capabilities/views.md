# Views

Views are saved table, kanban, and calendar configurations. The CRM ships with views built for the workflows teams actually run.

## Proposal and bid views

| View | Type | What |
|---|---|---|
| **Proposal Pipeline** | Table | Daily queue, sorted by proposal due date |
| **Estimation & Proposals** | Table | The proposal team's daily queue, including priority, proposal stage, and pricing complete |
| **Bid Tracker** | Kanban | Drag cards from RFP Received through Won, Lost, or No Bid |
| **My Active Bids** | Kanban | Per-user bid board |
| **Backlog** | Table | Won deals, sorted by substantial completion date |
| **Win/Loss by League** | Table | Won, lost, and no-bid deals grouped by league |

## Executive revenue views

| View | What |
|---|---|
| **Pipeline by Business Unit** | Table, grouped by business unit |
| **Revenue Forecast** | Table, forecasted opps ≥ 50% probability |
| **Top Open Deals** | Table, sorted by deal value |

## How to create a view

1. Open any object (Deals, Companies, etc.)
2. Apply filter + sort + columns
3. Click "Save as view"
4. Choose Table / Kanban / Calendar

Views can be shared by URL inside the workspace.

## Sharing a view

Open the view, copy the browser URL, and send it to a teammate who has CRM access. They will land in the same saved view.
